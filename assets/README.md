# Assets

Place website images in this folder and point to them from `content.js`.

Examples:

- `assets/project-1.jpg`
- `assets/fundraiser-flyer.png`
- `assets/event-photo.jpg`

Then update the matching card:

```js
{
  title: "Guest Speaker Series",
  description: "Invite professionals, alumni, or community leaders...",
  meta: ["Speaker", "Career Insight", "Networking"],
  image: "assets/event-photo.jpg"
}
```
