# Iota Beta

Static website for the Iota Beta professional development club.

## Files

- `index.html` contains the page structure.
- `styles.css` controls the design and animations.
- `script.js` renders the club content onto the page.
- `content.js` is the main file to update for new projects, fundraisers, events, text, and image paths.

## How To Update Content

1. Open `content.js`.
2. Edit the text in the `hero`, `feature`, and `about` sections.
3. Add, remove, or change cards inside `projects`, `fundraisers`, and `events`.
4. Put any new images into `assets/` and set the `image` value for a card to the file path.

If an `image` field is left blank, the site automatically shows a polished text placeholder instead.
